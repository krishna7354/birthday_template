# Birthday Surprise

A small interactive birthday website built with HTML, CSS, and JavaScript.

It opens in three stages:

1. A soft intro screen
2. A heartfelt message card
3. A final birthday collage with music, motion, balloons, petals, and confetti

## Features

- Multi-step birthday experience
- GSAP-powered entrance animations
- Confetti celebration
- Floating petals, sparkles, and balloons
- Background music with a floating play/pause button
- Photo collage and polaroid-style memory wall
- Responsive layout for desktop and mobile

## How To Run

Open `index.html` directly in a browser.

If you want the smoothest experience, use a modern browser like Chrome, Edge, or Firefox.

## Customization

- Update the written message inside `index.html`
- Replace photos in the `images/` folder
- Swap `song.mp3` with any birthday song you want
- Adjust colors, spacing, and motion in `style.css`

## Built With
